# Sistema de Gestión - Software FJ (Fase 4: Componente Práctico)

Repositorio oficial para el desarrollo del componente práctico del curso de Programación de la UNAD. El sistema simula la gestión de clientes, servicios y reservas para la empresa Software FJ, implementando Programación Orientada a Objetos (POO), manejo de excepciones personalizadas, registro de logs e interfaz gráfica de usuario.

---

## 🛠️ Tecnologías Utilizadas
* **Lenguaje:** Python (versión 3.x)
* **Interfaz Gráfica:** Tkinter
* **Control de Errores:** Excepciones personalizadas y módulo `logging` (`eventos_errores.log`)
* **Control de Versiones:** Git y GitHub
